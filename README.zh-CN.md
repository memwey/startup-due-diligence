一个开放的研究资料库，为工程师在加入科技初创公司之前评估公司提供有来源依据的事实。

> 本文与英文版同步至：2026-07-29。英文版为原始版本。

## 为什么做这个项目

选择是否加入一家初创公司并不容易。

传统的初创公司数据库通常关注：

- 融资
- 估值
- 投资者
- 市场规模

但工程师往往更关心：

- 公司正在解决什么问题？
- 工程师实际会参与哪些系统？
- 公开资料反映了怎样的工程环境？
- 关于公司业务进展和融资状况，有哪些可验证的证据？
- 加入之前还有哪些事情值得了解？

本项目收集判断这些问题所需的基础事实。它不会给公司打分、建议是否加入，也不能替代你自己的面试和尽职调查。

## 调研标准

本资料库以证据为先：

1. 优先采用产品文档、公司公告、企业登记和公司官方招聘信息等一手来源。
2. 每一个数字都应附上明确的来源和日期。
3. 由招聘信息或其他间接证据推导出的内容必须标明为推断。
4. 不擅自选择互相矛盾的说法，而是记录冲突本身。
5. 未找到公开信息只代表特定检索范围内的结果，不能证明相关信息或实践不存在。

完整的页面结构、来源优先级和发布检查清单见 [GUIDE.zh-CN.md](GUIDE.zh-CN.md)。

## 早期公司与创始人社交媒体

对于特别早期的公司，创始人的公开职业社交媒体账号可能是少数仍在更新的一手来源。公开内容可以用于：

- 寻找产品发布、招聘计划、客户公告，以及指向长篇资料的链接；
- 记录创始人的公开陈述，同时注明账号、原帖链接和日期；
- 发现可通过公司页面、企业登记、招聘信息或后续公告进一步核验的线索。

社交媒体内容需要比正式公司材料更严格的归因。创始人的陈述只能证明其公开说过这段话，不能独立证明陈述属实。愿景、估算和个人观点必须明确标注。调研不得使用私人或受访问控制的内容，不得收集与公司无关的个人信息，也不得根据个人动态推断其性格、公司文化或业务质量。

## 贡献

新增或更新公司之前：

1. 阅读 [GUIDE.zh-CN.md](GUIDE.zh-CN.md)。
2. 复制其中的公司页面模板。
3. 为每个数字和具有时效性的陈述附上带日期的来源。
4. 区分已经核实的事实、公司自身主张和研究者推断。
5. 完成指南中的发布检查清单，并设置 `Last updated`。

发布前运行双语一致性检查：

```bash
python3 scripts/verify_translations.py
```

欢迎使用更直接或更新的来源进行纠正。如果来源互相矛盾，应在公司页面中保留该矛盾，而不是不作解释地覆盖其中一种说法。

## 免责声明

本资料库包含根据公开信息独立整理的研究笔记，与所收录公司不存在关联。资料来源可能不完整，相关主张可能发生变化，信息也可能过时。在作出就业、投资或商业决定之前，请直接向公司及其他权威来源核实重要信息。
